RTX5090 部署 DeepSeek V4 指南

本指南演示如何在 RTX5090 上部署 DeepSeek V4，需要 CUDA13 与最新驱动。

安装步骤

docker pull deepseek/v4:latest
docker run --gpus all deepseek/v4:latest

硬件要求

型号显存FP4
RTX509032GB支持
RTX409024GB不支持

常用命令

nvidia-smi 查看 GPU 状态，更多见 官方文档。

Warning：升级固件前请备份数据。
